# ✨ Aditi Digital Playground

Welcome to my personal portfolio website! 💜

**Aditi Digital Playground** is a creative portfolio website where I showcase my web development projects, graphic designs, presentations, and other creative work.

This website represents my journey as a Computer Engineering student and my interest in combining technology with creativity.

## 🌸 What You'll Find

- 💻 Web development projects
- 🎨 Graphic design and Canva creations
- 📊 Presentation projects
- 👩‍💻 About me and my skills
- 📩 Contact section
- ✨ Smooth animations and aesthetic UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- SweetAlert2
- Google Slides Embeds

## 💖 Features

- Responsive design
- Purple and pink pastel aesthetic
- Glassmorphism effects
- Animated UI elements
- Project showcase
- Graphic design gallery
- Presentation showcase
- Consistent navigation across pages

## 🚀 How to Run

This is a static website, so no complicated setup is required.

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

That's it! 🎀
